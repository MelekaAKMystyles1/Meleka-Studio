# Meleka Creation Arts — Free ICT & Cyber Security Learning

A responsive, mobile-first educational website for free ICT and Cyber Security learning with multilingual support.

## Website
The site is published from the repository root for GitHub Pages.

## Included
- Premium responsive landing page
- Hero, learning paths, benefits, mission, testimonials, FAQ and CTA
- English / Chichewa / Swahili / French / Portuguese / Spanish interface switching
- Interactive course-path modal
- Mobile navigation
- Accessible semantic HTML and responsive CSS
- Defensive cybersecurity educational positioning

## Files
- `index.html` — website structure and content
- `styles.css` — responsive visual design
- `script.js` — menu, language switcher and course interactions
- `404.html` — Pages fallback

## Note
The testimonial cards are clearly labeled as community-profile placeholders until verified learner stories are collected.
