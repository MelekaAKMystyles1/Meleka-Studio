FAQ

Questions before you start?

Here are the essentials. More course-specific answers can be added as new lessons launch.

Is the learning really free?+

Yes. The platform is designed around free access to core ICT and Cyber Security learning.

Do I need previous ICT knowledge?+

No. The foundation path starts with beginner concepts and gradually introduces more technical ideas.

Can I learn from a phone?+

Yes. The website is mobile-first, with lightweight layouts designed for smaller screens and slower connections.

Which languages are supported?+

The interface currently demonstrates English, Chichewa, Swahili, French, Portuguese and Spanish. Course translation can expand over time.

Does this teach hacking?+

The focus is defensive and educational: understanding threats, protecting systems and practicing cybersecurity responsibly and legally.
